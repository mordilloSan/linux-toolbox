# Security policy

## Supported versions

Security fixes are applied to the latest release and the `main` branch. Older
releases are not supported; update to the latest version before reporting an
issue that may already be resolved.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue, pull
request, or discussion.

Use GitHub's [private vulnerability reporting](https://github.com/mordilloSan/linux-toolbox/security/advisories/new)
to submit a report. Include, where possible:

- A description of the vulnerability and its potential impact.
- The affected version, script, and Linux distribution.
- Steps or a minimal example that reproduces the issue.
- Any suggested mitigation or fix.

If private reporting is unavailable, open an issue requesting a private contact
channel without including vulnerability details.

You can expect an acknowledgement within five business days and an initial
assessment within ten business days. Confirmed vulnerabilities will be handled
through coordinated disclosure, with updates provided until a fix is released
or the report is closed.
